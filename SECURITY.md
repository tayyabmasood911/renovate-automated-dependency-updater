# Security Policy

## Supported Versions

Only the dependency management rules and presets on the `main` branch are supported.

| Version | Supported          |
|:--------|:------------------:|
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Security Issue or Supply Chain Risk

If you discover a malicious dependency injection vector, regex ReDoS flaw, or configuration bypass:

1. **Do not create public GitHub issues**.
2. Email maintainer **Tayyab Masood** at **tayyabmasood911@gmail.com** with the subject `[SECURITY] Renovate Supply Chain Report`.
3. Provide details of the package rule or regex pattern involved and potential supply chain impact.

All reports will be acknowledged within 24 hours.
